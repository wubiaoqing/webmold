WebMold 设置

模型接入（OpenAI 兼容）

支持标准 OpenAI 及任何兼容 Chat Completions 的服务。API Key / 代理 token 仅存储在本地浏览器中。

选择预设云厂商会自动填入 BaseURL 与默认 API Key，并展示该厂商支持的模型。 目前内置腾讯云 Token Plan，更多厂商（如阿里云）将陆续接入。

填到 /chat/completions 之前的部分，例如 OpenAI 为 https://api.openai.com/v1。

从上方下拉选择会自动填入下方输入框；也可手动输入下拉中没有的模型或私有服务 server:<serverId>。带 [工具] 标记的模型支持 function calling（本扩展 agent 依赖此能力，建议优先选择）。

高级设置

gpt-5 及后续版本会自动映射为 max_completion_tokens；留 0 时自动使用当前模型允许的最大输出上限，避免长规则的 JS/CSS 被截断。填入的值不会超过模型能力上限。

填写后，云厂商与模型列表可独立于扩展版本更新（如新增云厂商 / 模型），无需升级插件； 留空则使用扩展内置清单。配置 JSON 格式： { "version": "...", "providers": [...] }，providers 数组结构与内置清单一致（含 id / name / baseUrl / models）。
