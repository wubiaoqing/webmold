WebMold 隐私政策

最后更新日期：2026-08-11

一句话总结：开发者不收集、不存储、不传输你的任何数据。所有数据都留在你自己的浏览器里。

1.开发者收集的数据

本扩展的开发者不收集任何用户数据。本扩展没有任何服务器端、没有账号系统、没有遥测统计，也没有广告。

2.数据存储

  • 所有规则、配置、历史记录均存储在用户浏览器本地的 chrome.storage.local 中。
  • 用户填写的 API Key / Token 仅保存在浏览器本地，开发者无法访问。
  • 卸载扩展后，浏览器会在符合其清理规则时移除相关本地数据。

3.数据的处理与传输

当用户主动使用「生成定制」功能时，扩展会把当前页面的标题、DOM 结构摘要以及用户输入的需求， 发送到用户在设置页自行配置并授权的第三方 AI 模型服务（OpenAI 兼容接口），以生成 CSS/JS 规则。 开发者不参与也不存储这些请求内容。

4.第三方服务

本扩展依赖用户自行配置的第三方 AI 模型服务（如腾讯云 Token Plan、DeepSeek、Kimi 等）。 该服务的数据处理行为由其自身隐私政策约束，与开发者无关。请在使用前阅读你所选服务的隐私政策。

5.用户控制

  • 用户可随时在设置页删除、修改或导出自己的规则与配置。
  • 用户可随时卸载本扩展，停止一切数据处理。

6.联系方式

如有隐私相关问题，可通过 GitHub 仓库 issue 联系开发者。

本隐私政策随扩展版本更新，如内容变更将在此页面说明。
