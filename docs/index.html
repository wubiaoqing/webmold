说一句，网页听你的

WebMold 是一个 AI 驱动的浏览器扩展。用自然语言描述你想对任意网站做的改动， 内置 Agent 会直接在你的真实页面上「探测 → 试跑 → 验证」，把需求翻译成可执行的 CSS / JS 并注入生效。不用写一行代码。

核心特性

不是「一次性猜代码」，而是一个循环式工作的 Agent：先看、再试、后落库。

🤖

Agent 驱动

循环执行「探测 → 试跑 → 验证」，先在真实页面上确认可行性，再产出规则，复杂网站成功率更高。

🎛️

功能 + UI 双定制

CSS 管外观，JS 管功能。隐藏广告、加夜间模式按钮、给卡片补时长……能力上限接近手写脚本。

🗂️

按域名持久化

规则以域名为维度保存，支持整站 / URL 前缀 / 精确 URL 三种生效范围，下次访问自动生效。

👁️

即时预览

保存前先预览效果，满意再落库；Agent 每一步的思考与工具调用都在侧边栏实时可见。

🧩

规则管理

启用 / 停用 / 编辑 / 删除 / 导入导出，随时调整，全部数据掌握在自己手里。

🔌

模型自选

兼容 OpenAI Chat Completions 协议，内置腾讯云 Token Plan 模型清单（GLM / Kimi / DeepSeek / MiniMax 等），也支持接入任何自建服务。

三步上手

从安装到第一个规则生效，只需要一分钟。

安装并配置模型

按下方「安装」区加载扩展，在设置页选择模型厂商（如腾讯云 Token Plan），填入自己的 API Key 并测试连接。

打开网页，说需求

打开任意网站，点击工具栏 WebMold 图标打开侧边栏，输入「隐藏顶部广告」这类自然语言需求，点击 生成定制。

预览并保存

观看 Agent 实时探测与试跑，确认预览效果后选择生效范围（整站 / URL 前缀 / 精确 URL），保存即可。之后每次访问自动应用。

安装

目前以开发者模式加载安装。商店版本正在准备中。

Chrome推荐

  1. 下载下面的安装包并解压（注意不要删除解压后的文件夹）；
  2. 打开 Chrome，地址栏访问 chrome://extensions；
  3. 右上角开启「开发者模式」；
  4. 点击「加载已解压的扩展程序」，选择刚才解压的文件夹；
  5. 把 WebMold 图标固定到工具栏即可使用。

Edge / 其他 Chromium 浏览器

  1. 同样下载并解压安装包；
  2. 访问 edge://extensions，开启「开发人员模式」；
  3. 点击「加载解压缩的扩展」并选择文件夹。

隐私与安全

本地优先，默认不上传任何数据。

  • ✓默认纯本地存储（chrome.storage.local），无遥测、无账号、无服务器端。
  • ✓API Key / Token 仅保存在浏览器本地，开发者无法访问。
  • ✓Agent 的探测工具默认只读；试跑脚本带 8 秒超时。
  • ✓只有你主动点击「生成定制」时，才会把页面标题、DOM 摘要和你的需求发给自配的模型服务。
⚠️ 生成的 JS 会在页面主世界执行，等同于第三方脚本。保存前请务必点击「预览」检查生成代码。
