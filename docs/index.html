用一句话定制任意网站

WebMold 是一个浏览器扩展。打开任意网页，描述你想做的改动（比如「隐藏顶部广告」「给标题加个夜间模式开关」）， 内置 Agent 会在你的真实页面上探测结构、试跑方案、验证可行，最后生成 CSS/JS 规则注入生效，并按域名持久化。

# 你在侧边栏输入：

# Agent 执行过程（实时可见）：
[detect] 读取 DOM 摘要… 42 个候选节点
[locate] 命中广告条 #ad-banner-1 ✓
[probe] 试跑 CSS：display:none，无布局抖动
[probe] 正文 .article { max-width: 960px }
[draft] 生成规则 → 待你预览确认
[save] 已保存至域名 news.example.com（整站生效）

特性

核心不是「一次猜代码」，而是一个会循环工作的 Agent：先探测、再试跑、后落库。

Agent 驱动核心
循环执行「探测 → 试跑 → 验证」，先在真实页面上确认可行再产出规则。复杂站点的成功率更高。
功能 + UI 双定制
CSS 管外观，JS 管功能。隐藏广告、加夜间模式按钮、给卡片补交互……能力上限接近手写脚本。
按域名持久化
规则以域名为维度保存，支持整站 / URL 前缀 / 精确 URL 三种生效范围，下次访问自动应用。
即时预览
保存前先预览效果，满意再落库。Agent 每一步的思考与工具调用都在侧边栏实时可见。
规则管理
启用 / 停用 / 编辑 / 删除 / 导入导出，随时调整。所有数据掌握在自己手里。
模型自选
兼容 OpenAI Chat Completions 协议。内置腾讯云 Token Plan 模型清单（GLM / Kimi / DeepSeek / MiniMax 等），也支持接入任何自建服务。

用法

从安装到第一个规则生效，约一分钟。

安装并配置模型

按下方安装区加载扩展，在设置页选择模型厂商（如腾讯云 Token Plan），填入自己的 API Key 并测试连接。

打开网页，输入需求

打开任意网站，点击工具栏 WebMold 图标打开侧边栏，输入类似「隐藏顶部广告」的需求，点击 生成定制。

预览并保存

观察 Agent 实时探测与试跑，确认预览效果后选择生效范围（整站 / URL 前缀 / 精确 URL），保存。之后每次访问自动应用。

安装

当前以开发者模式加载。商店版本正在准备中。

webmold.zip v0.1.0 · ~97 KB
下载安装包
chrome edge / chromium
  1. 下载上面的安装包并解压（解压后请勿移动或删除该文件夹）；
  2. 打开 Chrome，地址栏访问 chrome://extensions；
  3. 右上角开启「开发者模式」；
  4. 点击「加载已解压的扩展程序」，选择解压出来的文件夹；
  5. 把 WebMold 图标固定到工具栏即可使用。
Edge 用户访问 edge://extensions → 开启「开发人员模式」→「加载解压缩的扩展」，步骤一致。

首次打开会进入欢迎页；使用前需在设置页配置一个 OpenAI 兼容的模型服务（填入你自己的 API Key / Token）。

隐私与安全

本地优先，默认不上传任何数据。

  • ok默认纯本地存储（chrome.storage.local），无遥测、无账号、无服务器端。
  • okAPI Key / Token 仅保存在浏览器本地，开发者无法访问。
  • okAgent 探测工具默认只读；试跑脚本带 8 秒超时。
  • ok只有你主动点击「生成定制」时，才会把页面标题、DOM 摘要和你的需求发给自配的模型服务。
生成的 JS 会在页面主世界执行，等同于第三方脚本。保存前请务必点击「预览」检查生成代码。
