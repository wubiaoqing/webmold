WebMold

说一句, 网页听你的 · Say it, Shape it

用一句话，把任意网站改成你想要的样子

能用它做什么？

下面是一些常见玩法，点开侧边栏直接照着描述即可 —— 越具体，生成越准。

🚫去广告 · 去干扰
  • 隐藏顶部横幅广告和右侧悬浮推广
  • 去掉「猜你喜欢 / 相关推荐」模块
  • 关掉自动播放视频、移除右下角客服弹窗
📖阅读体验优化
  • 给这个网站加个夜间模式，深灰背景浅色文字
  • 正文字体调到 18px、行高 1.8，宽度限制 800px 居中
  • 去掉所有动画和渐变，界面越简洁越好
✨信息增强
  • 在每个视频卡片上显示时长和播放量
  • 商品列表价格加粗放大，低于 100 元标红
  • 在每条搜索结果标题后显示它的域名
⚙️功能增强
  • 加一个「回到顶部」悬浮按钮
  • 滚动到底部时自动加载下一页
  • 把页面所有外链都改成新标签页打开
🧩布局重排 · 精简
  • 把后台系统左侧的侧边栏默认折叠起来
  • 只保留导航里的「首页 / 我的」，其余隐藏
  • 把双栏布局改成单栏，只留主内容区
⚡特定站点提效
  • 视频站：记住清晰度、自动跳过片头
  • 电商站：隐藏已售罄商品，只看有货的
  • 文档站：右侧加一个当前页大纲目录
  1. 1

    配置模型（必做）

    在设置页填写 BaseURL、API Key、模型名称，点「测试连接」确认可用。兼容 OpenAI Chat Completions 的服务均可，建议选支持 function calling 的模型。

  2. 2

    打开侧边栏，描述需求

    点工具栏 WebMold 图标打开侧边栏，用自然语言说出你的定制（参考上面的常见玩法），点「生成定制」。

  3. 3

    预览、保存，自动生效

    预览生成的 CSS/JS（可微调）→ 选生效范围 → 保存。之后访问该网站自动应用。

安全提示

最终生成的 JS 会在页面主世界执行，等同于运行第三方脚本。保存前请务必预览并检查生成的代码。 API Key 仅存储在浏览器本地，不会上传到除你配置服务之外的任何地方。
